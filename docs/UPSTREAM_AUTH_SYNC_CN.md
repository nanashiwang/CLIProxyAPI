# 上游认证结果策略与更新排序融合

本次仅选择性融合上游 dev 的 `2912516cea7b591dff17d19abfa84d3354a1448c` 和 `d1702fdffd2bb6903f985c60688ecf63f3b18ca2`，不合并 dev 的其他提交。

## 结果策略

SDK 可通过 `Builder.WithResultPolicy`、`Service.SetResultPolicy` 或 `auth.Manager.SetResultPolicy` 安装策略。在 `MarkResult` 变更成功/失败计数、额度、冷却、持久化及发布调度状态之前调用策略，后续 hook 接收调整后的结果。默认没有策略，保持原有行为。策略需要支持并发调用；清空结果的 AuthID 可丢弃该结果的状态更新。

本地凭证级 429 传播、路由模型冷却投影、有效冷却期限只延长不缩短的逻辑继续使用。将 CredentialScope 降为 false 后，只按模型处理额度，不再触发凭证级扩散。策略只调整内部执行结果记录，不改变上游实际响应，也不授予新的账号分组权限。

## 认证事件排序

Watcher 的每账号递增 revision 区分文件事件的新旧，同一服务串行处理认证更新，丢弃较旧或重复 revision，保留删除 revision，防止旧事件重新添加已删除账号。注册周期 RegistrationEpoch 阻止旧账号实例的更新和删除作用于重建后的同 ID 账号。

不使用 Generation 或 UpdatedAt 直接判定文件事件过期：执行结果和冷却也会更新这些字段，不能因此吞掉真实的新文件修改。

管理端启停认证会在持久化后同步更新运行时模型和调度，使用独立于请求取消的上下文；状态接口通过专用锁串行化。Watcher 队列稍后送达的重复事件被 revision 过滤。

相对上游另作两处收敛：旧注册周期更新在执行器与模型注册前直接退出，避免仍然推进模型注册版本；运行时配置未就绪时不提前消费 revision。

## 与本地功能的边界

- 保留 OpenCode 目录代理与初始化逻辑，解决 Builder 中新增方法的文本冲突。
- 账号分组继续从当前运行配置解析，不由认证更新或结果策略修改。
- 独享租约仍绑定单个账号一小时，结果策略不续期、释放或重新分配租约。账号冷却时原用户不能换号，同组其他空闲账号可供其他用户使用。
- 租约状态保持 v2，无状态迁移；不修改管理前端及线上服务。
- Home 临时认证仍通过既有独立结果上报流程处理；本次新增策略作用于本地 `MarkResult` 路径。

## 回归覆盖

包含上游策略前置、SDK 接线、管理启停同步、请求取消与乱序事件测试；另补充：

- 旧注册周期的修改/删除不改变认证、冷却和模型注册版本。
- 乱序批次选择较新 revision、重复事件无副作用、删除后旧事件不能复活账号。
- 执行结果推进 Generation 后，新文件快照仍生效且保留凭证冷却和分组权限。
- 策略降级/丢弃结果时，保持租约账号、原到期时间及在途计数；模型冷却禁止换号，兄弟模型和同组其他空闲账号可正常使用。
- 无队列时仍分配 revision，并拒绝重新排入旧观察结果；运行时就绪前不吞掉 revision。
