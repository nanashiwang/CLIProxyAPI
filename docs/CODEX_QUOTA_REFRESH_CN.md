# Codex 额度窗口复核与独享租约

## 借鉴范围

参考 `zyycn/codex-proxy-rs` 的提交 [`d0180b74b3eed06073a65528cbca502f0e1ca6bc`](https://github.com/zyycn/codex-proxy-rs/commit/d0180b74b3eed06073a65528cbca502f0e1ca6bc)。选择性采用重置宽限期、周期复核节流、保留已观察用量的规则；没有合并其 Rust 服务、数据库结构、管理页面、账号选择器或租约实现。

原 CPA 只有请求错误驱动的冷却和用量事件采集，没有后台额度窗口复核器。本次在现有 auth manager 中增加本地 Codex OAuth 额度观察与复核，保留原账号池、组权限、独享归属和流生命周期。

## 行为

- 后台每 30 秒检查候选账号，最多 4 个并发请求、每轮最多 100 个账号；尚无观察的账号初始化一次，失败复用 30 分钟节流。
- 正常账号仅在非零用量窗口经过 `reset_at + 2 分钟` 后复核。即使没有刷新历史，也不能绕过宽限期。
- 已确认耗尽的账号首次立即复核，此后每 30 分钟复核，不等待旧 reset，以发现上游提前恢复；最早未恢复窗口的 `reset_at + 2 分钟` 可额外触发一次复核。
- 同一 reset 边界已复核后，若上游仍返回旧值或请求失败，回到周期节流，避免每轮重复探测。
- 时间到期不会清零 `used_percent` 或直接解除已确认耗尽。数字 100% 本身不等同于上游明确拒绝。
- HTTP 额度响应头和 WebSocket `codex.rate_limits` 更新原始观察；被动观察不会解除明确耗尽。主额度与其他命名额度保持隔离，其他命名额度仍由原有统计路径采集。
- 复核只读取 `https://chatgpt.com/backend-api/wham/usage`。只有明确允许、有效用量和每个已耗尽窗口的恢复证据才能恢复路由：窗口 reset 推进且用量低于 10%，或 reset 未推进时连续两次观察均可用。单次滞后快照不能解除耗尽。缺失窗口不会被视为零用量；按窗口时长匹配，避免 primary/secondary 调换导致错误归因。套餐改变且旧耗尽窗口消失时保守保留限制，可由管理员核实后手动恢复。
- 探测网络错误、非 200、格式错误或缺失窗口保持最后有效观察，不写入生成请求计数，也不触发租约切换。
- API Key、自定义 base URL、插件虚拟账号、Home 调度、禁用/401 失效账号及已过期 OAuth token 不做本地后台探测。token 更新仍交给原有凭据刷新机制。

## 并发与冷却

额度复核的预约与在途状态在 manager 锁内更新，同一账号不会重叠探测。周期节流使用 Go 的单调时钟间隔；reset 边界使用上游墙钟时间。

开始和提交复核时校验注册 epoch、generation、账号身份和 token。并发 429、新被动观察、配置重载、手动恢复、token 更新或删除重注册后，旧结果不能覆盖新状态。旧注册周期的生成结果也不能给重注册账号写入耗尽状态。

恢复只清理对应额度故障，保留认证错误、模型错误、通用限流和较长的其他冷却。关闭 cooling 可绕过额度调度限制，但保留原始观察；管理员手动恢复解除本地耗尽标记，也不伪造已观察用量。

快照放在现有 cooldown store 的账号记录中，兼容文件 `.cds` 和 Postgres JSON 记录，无数据库迁移。重启后保留过期窗口的用量和耗尽归因。被动流事件的写盘每 5 秒合并一次，正常停止时补写；异常断电最多可能丢失最近尚未落盘的被动观察。明确请求失败仍沿用原有冷却持久化路径。

管理接口 `/v0/management/auth-files` 增加可选 `codex_quota` 快照字段，旧管理页面仍兼容；不要求同步修改管理中心。

## 独享账号池和续接

后台额度 GET 不分配、替换、续期或释放用户租约，也不创建 Responses/WebSocket 会话。

单账号独享组确认提前恢复后，保留原租约 ID、账号归属和到期时间，原账号的 `previous_response_id` 可按原有规则续接。若账号已经被原有故障切换逻辑替换，恢复旧账号不会回绑旧租约，也不能放行旧续接 ID。

下游取消后，上游流生产者尚未关闭时仍保持 Active 占用；额度恢复不能释放占用，其他用户不能抢占账号。已有流式输出不会因后台探测被重放。

## 发布与部署

沿用 `personal/main` 自动测试、打 `personal` 版本标签和全平台 Release 流程。配套部署包包含本版源码差异、现有正式管理页面、构建参数、中文部署说明和摘要，上传后回下载逐字节核验。

部署前备份服务二进制、token 目录、cooldown store 和租约状态文件；使用现有服务部署方式替换对应平台二进制并重启。无需新增必填配置。不要删除 `.pool-leases.state` 或锁文件，也不要把实际 token、配置、数据库或日志加入公开部署包。

回滚可恢复上一版二进制。旧版忽略额外快照字段，但不具备本版“确认恢复后才解除耗尽”的语义。发布不代表线上服务已更新。
